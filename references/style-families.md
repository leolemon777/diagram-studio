# 六套风格家族：构图先于颜色

画布比例、横竖重排、分辨率和打印密度见 [画布尺寸与排版](canvas-sizing.md)。不传尺寸参数保留原图版；需要固定原构图时选 `fit`，需要按用途重排时选 `adaptive`。

用户喜欢 Lieflat Charts、归藏 PPT Skill、Kami 的视觉方向，要求更多有辨识度、能跨图型使用的风格。本文件是独立设计的提炼，不是三个项目的模板移植。用户尚未逐套选定；新要求始终覆盖默认值。

若重点是 Lieflat 的精致**数据图形**，转到 [data-art.md](data-art.md)：其中12类配方有可数单位、逐条记录、分布计算与双阅读模式。本文四种有界结构图版仍保留，不用鱼骨/架构的通用外框替代数据编码。

## 选择和组合

先确定图型和内容，再选风格家族，最后调整配色。`assets/style-families.json` 中六套参数包含颜色、版式、签名和适用场景。原七主题是配色维度，本轮六家族是构图维度，两者不要混称为十三种等价风格。

| 家族 ID | 识别特征 | 优先用途 | 内容密集时的取舍 |
|---|---|---|---|
| folio 蓝墨书页 | 宋体大标题、双细线、蓝墨、图版编号和三栏图注 | 架构总览、科研图版、正式说明 | 先保留图体宽度，图注放到下一页 |
| ledger 计量手札 | 观察侧栏、编号记录、细刻度、橄榄灰 | 现场诊断、能源、工位分析 | 旁注可移到下方；不能把主体文字压到不可读 |
| cut 留白切面 | 严格网格、大号索引、深色题签、直角模块 | 管理汇报、流程、指标比较 | 收短标题，放大证据；避免重复卡片淹没关系 |
| archive 朱砂档案 | 竖向边栏索引、细框、朱砂小面积强调、旁批 | 因果复盘、研究附图、分析记录 | 仅保留一个外框；红色不自动表示故障 |
| dune 沙丘刊物 | 不对称双栏、衬线命题、偏置图版、明显阅读停顿 | 改善故事、提案、研究摘要 | 复杂鱼骨/网络改用宽图，不强留左栏 |
| graphite 石墨图谱 | 石墨底、骨色线稿、端口、定位角、技术题签 | 技术架构、工艺、运行分析 | 保持文字/线条对比；打印时可转浅色配方 |

区分风格至少涉及版面区域、字级、注释位置、模块/数据标记中的两项。只换色不算新家族。鱼骨主干、判断菱形、共享坐标轴等语义必须保留；不为追求形式强行改图型。

## 字体、字色和线条配方

每个家族的 `type` 和 `stroke` 参数与颜色一起存放在 `assets/style-families.json`。主图的语义排布完成后，按角色应用标题、分类、节点正文、注释、数字字体；场景文件保留 `role`，可继续编辑。文字采用独立的 `title_ink`、`body_ink`、`secondary_ink`、`category_ink`，关系线用 `relation_ink`，不再让一套墨色承担所有层级。`--colors` 支持这些具体角色；覆盖 `ink/accent/muted` 会联动相应角色，单独指定角色时以具体值为准。

| 家族 | 文字处理 | 线条处理 |
|---|---|---|
| 蓝墨书页 | 宋体标题和正文，Baskerville 数字；蓝墨标题、暖灰正文 | 2.1px 主干，1.25px 鱼骨枝，0.65px 辅线；开口箭头 |
| 计量手札 | 清晰黑体，Menlo 数字和索引；深绿墨正文 | 1.7px 主干，1.05px 枝，短虚线；开口箭头 |
| 留白切面 | 轻字重大标题、较强节点标题，Helvetica Neue 数字 | 3.2px 主干，2.3px 流程关系；实心箭头与方端点 |
| 朱砂档案 | 宋体、Baskerville；赭墨标题、深褐正文与朱砂分类 | 1.9px 主干，1.1px 枝，圆端点、点状虚线；开口箭头 |
| 沙丘刊物 | 常规宋体与古典数字，暖棕字色分层 | 2.5px 主干，1.3px 枝，长虚线；实心箭头 |
| 石墨图谱 | 黑体与等宽数字，骨白标题、浅灰正文、铜色分类 | 2.5px 主干，1.4px 枝；空心箭头、方端点 |

以上像素以1600宽画布为基准。换图型或尺寸需重新判断阅读距离，不把参数当不可变规范。业务文字与关系保持一致；文案可简化但不能更改判断、数值、单位或因果状态。

macOS 的 `Songti.ttc` 第一张字面是 Black（900），直接交给 Matplotlib 会把常规宋体误画成黑体重。脚本按真实字面分别注册系统字库中的 Regular/Light/Bold，并在临时缓存中使用，Skill 不打包字体二进制。PNG/PDF 使用实际数字字重，不把500一律转换成Bold；SVG使用浏览器本机字库，跨环境仍须检查字体回退。

## 可执行的范围

`scripts/style_family.py` 是四种有明确容量的示范图版，不是覆盖全部目录的自动布局器：

- 鱼骨：六组、每组三项；保留 18 项原因 ID、完整详情和模拟假设；画面可用较短的 `display_label`。优先项表示待验证顺序，不暗示已证实。
- 架构：三层、每层两模块，五条逻辑流和一条反馈。家族决定横向分栏或纵向分层。连接含稳定节点端点。
- 流程：五步，第四步是验证菱形，含是/否路径。大图横向排列，侧栏版折行；不冒充 BPMN 全规范。
- 趋势：十二期两条正数单耗序列，按各自第一期归一到 100；共享显式坐标轴，保留原始单位。线型和标记共同区分系列，不依赖颜色。使用 Matplotlib 导出 PNG/PDF；矢量源独立保留。

超出容量时选择现有 `render.py`、统计后端或另写布局，并应用本文件的视觉规则。不要静默截断数据，也不要把错误提示当作不需要作图。

```bash
python3 <skill-dir>/scripts/style_family.py \
  <skill-dir>/assets/style-family-examples/fishbone.json \
  --family archive --out <output-dir>
```

窄栏标题可用 `narrow_title` 提供语义合理的手动换行。

输出 SVG、原生 draw.io 图元、PNG、PDF、输入 JSON、图元场景 JSON、计算 JSON、QA JSON。PNG/PDF 需要 Matplotlib；只需 SVG/draw.io 时加 `--vector-only`。字体使用本机 Songti SC / PingFang SC 或 Noto CJK 回退，不打包第三方字体。换机器需检查字体回退和字宽。draw.io 中趋势线是可编辑图元，不是带电子表格公式的图表；改数据应修改 JSON 后重绘。

用户可覆盖六个颜色 token，不改变结构：

```bash
python3 <skill-dir>/scripts/style_family.py brief.json --family folio \
  --colors '{"bg":"#F1EFEB","accent":"#846451"}' --out output
```

## 跨形式适配

以下四行已做六家族成图；之后的形式是迁移指导，尚未完成全家族渲染验证。

| 形式 | 不变的语义 | 可变化的风格部位 |
|---|---|---|
| 鱼骨（已成图） | 主干效果、原因分类、待验证假设、18 项来源 | 外部题签、组名字体、旁注、细线与小面积强调 |
| 架构（已成图） | 模块/层级/连接/反馈方向 | 横向栏或纵向层、端口、边界、说明栏 |
| 流程（已成图） | 执行顺序、决策、完整分支、返工路径 | 平铺或折行、责任人副标题、阶段编号 |
| 趋势（已成图） | 数值、单位、基期、时序、同轴比例 | 线/刻度/点标、图注布局、网格强度 |
| 组织/树状图 | 父子关系、节点级别 | 书页缩进、纵向分支、分组旁注；勿让字号取代关系 |
| 时间线/甘特 | 日期比例、依赖、持续时长 | 表头、阶段标签、日期轨道；不能把等宽卡片当真实时长 |
| 三线/消融表 | 数值精度、列含义、最优/次优和不确定性 | 字体与留白、行组侧注；不用全面底色破坏三线表 |
| 散点/分布/森林 | 观测、区间和统计定义 | 论文图版/计量手札；只在真实点上加数据标记 |
| 热图/相关矩阵 | 连续或发散色标、零点、缺失值 | 页底与注释可继承；色标仍按数据语义设计 |
| 网络/桑基 | 拓扑、方向、流量守恒 | 图注与字体可迁移；线宽保留量纲，不按装饰改宽 |

## 家族提示词

在图型专用提示词之后，按所选家族增加一段；不要同时加载六段。

**folio**：将 {需求} 排为可引用的研究图版。用暖灰纸底、蓝墨与宋体标题，题签和图注形成书页层级。主体占完整阅读宽度，下方三个短图注解释依据、边界与下一步。保持原始关系和数值，保留假设与来源。

**ledger**：将 {需求} 排成现场观测手札。侧栏只保留三条有用的观测/验证记录，主图表达事实。数据标记逐点对应真实记录；使用细刻度，不制造装饰性“数据”。密度过高时把侧栏移到底部，并拆解主图。

**cut**：用严格网格和一个强调色组织 {需求}。标题、索引、深色题签与证据图形成四级层次。节点用直角块，文字清晰；优先呈现关键比较和决策路径。大字用于主旨，不能拿模糊大数字冒充指标。

**archive**：把 {需求} 排成清晰的分析档案。使用暖纸、细框、克制朱砂索引和边栏编号。旁批补充证据状态；红色不自动意味着风险。避免装饰印章、仿旧污迹或与主题无关的书法。

**dune**：把 {需求} 排成双栏研究短文：左侧是简洁命题与依据，右侧是完整图版。用衬线标题、温暖低饱和色和大留白建立阅读停顿。长标题主动分行但不留下孤立标点；图体复杂时取消侧栏。

**graphite**：将 {需求} 制成深石墨工程图版。骨色线稿、小号技术题签、真实连接端口与少量定位角建立秩序。保证箭头和文字在暗底上清晰；不加霓虹、发光或无意义网格。图例解释实线、虚线和反馈。

## 完成检查

- 对照输入：六种风格的模型摘要和计算结果必须相同，节点或关系不能因排版消失。
- 看整图与 100% 文字；检查孤字/孤立标点、注释撞线、菱形外的装饰线、折行后的分支标记。
- 尤其检查架构回路与页脚间距。图库缩略图不能替代完整图检查。
- 已有能力只声明到 6 家族 × 4 形式；其它形式按上表迁移后需要重新检查。不因 24 张样图而改写目录完成率。

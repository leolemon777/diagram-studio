# 工程、平面、地图与科研图示

这些图不能仅靠提示词美化。先确定是沟通示意、教学解释，还是依据标准和尺寸用于实施。

## 电气 / 工业控制

分别处理功能框图、原理电路、接线图、梯形图、单线图。保持符号标准一致，位号唯一；端子、触点状态、交叉/连接点、参考电位都有明确含义。动力与控制回路可分区，图签包含版本和图纸用途。未经电气计算/专业检查，不能称为可直接施工的工程文件。

## PFD / P&ID

PFD 偏重主要设备与物料过程；P&ID 增加管路、阀门、仪表和控制关系。设备位号、管道编号、介质流向、信号线类型有图例。工艺管线与控制信号不能共享一种不加解释的线。现有生成器的矩形/线条只适合概念框图，正式符号应使用验证过的元件库。

## 平面布置与地图

保留长度单位、比例尺、方向、门开启与通行边界。实测尺寸未知时标注“布局示意，非测量图”；不能为美观移动实际设施或改变逃生可达性。GIS 边界与地理数据用可靠来源，不手绘误导性边界。

办公室、座位、门禁、疏散、暖通、电气与通信、端子接线、单线和给排水已有专用输入合同与渲染器，优先读取 [设施与工程平面模型](facilities-engineering.md)。专用后端只验证已声明的尺寸、关系、可达性、系统平衡或坡度，不替代现场测量、属地审批和专业设计。

电路与逻辑、系统图、线路/地理地图、基础科学示意、SysML、商务出版物、质量管理、国产云架构和故事分镜的最终常用批次见 [最终常用类型](final-common-types.md)。使用 `remaining_types.py` 前先确认对应模式；它会校验各图型的真值表、守恒、约束、拓扑、内容角色、阅读顺序、可用区或镜头时长。

## 科研与技术路线

输入问题→假说→研究任务→方法/材料→验证→预期产出。事实机制与待验证机制区分；箭头不自动表示因果。实验分组、样本量、统计方式来自真实方案。复杂生物/化学结构需专业工具与领域校核。

## 历史和专用建模法

遇到 IDEF / SDL / SSADM / Jackson / ROOM / N-S 等请求，先确认具体变体及规范，再查权威资料。不要凭名称或相似形状声称正式兼容。可先交明确标注的逻辑示意，并说明还缺什么语义/符号验证。

P&ID连接模型与逐项缺口见 [拓扑输入合同](pid-topology.md)。已有供水测压教学拓扑与可编辑示意；完整标准符号与DEXPI交换仍未实现。

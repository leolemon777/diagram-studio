# 符号、连线与语义

符号先服务定义，再服务外观。这个文件是原创设计规则；不包含万兴图示的素材包或全部标准图形。实际观察的内置符号库入口见 `assets/native-symbol-inventory.json`，公开类型的原始库 ID 见 `assets/official-types.json`。

| 图族 | 节点语义 | 连线语义与端点 | 核对要点 |
|---|---|---|---|
| 基础流程 | 起止、动作、判断、输入输出、文档、存储 | 有向执行，分支附条件 | 判定出口完备；回路能退出；文档不当动作 |
| BPMN | 事件、任务、子过程、网关、池与泳道 | 顺序流、消息流、关联互不混用 | 池之间不能跨顺序流；开始/结束/中间事件符号区分 |
| UML 类 | 类、接口、枚举、包、实例 | 关联、依赖、泛化、实现、聚合、组合 | 三角、菱形、虚实线和基数端点各有含义 |
| UML 行为 | 状态、伪状态、动作、生命线 | 转换、控制流、对象流、消息 | 事件/守卫/动作顺序；并发与选择区分 |
| 数据流 DFD | 外部实体、处理、数据存储 | 箭头是数据，不是程序控制 | 不跨层凭空增减外部输入输出 |
| ER/ORM | 实体、属性、关系，或对象/角色/事实 | 最小最大基数、可选性、标识关系 | Chen、乌鸦脚、ORM 不能混用符号却不解释 |
| 组织与家系 | 岗位、部门、成员 | 汇报、协作、婚配、亲子分开 | 多重父母/汇报关系不强塞进普通树 |
| C4/架构 | 人、系统、容器、组件、部署节点 | 使用/调用/发布/读取等带动词关系 | 抽象层次一致；边界与运行实例对应 |
| 网络 | 路由、交换、安全设备、端点 | 物理连接、逻辑可达、业务协议 | 端口、子网和站点信息不能靠图标猜测 |
| 工程电气 | 电源、元件、端子、参考地 | 导线、总线、连接点、屏蔽 | 交叉和连接区别；极性、常态、编号一致 |
| PFD/P&ID | 设备、阀门、仪表及位号 | 物料管线、信号、控制逻辑 | 信号线型和回路位号有图例；仪表不当普通圆形装饰 |
| 平面与地理 | 边界、墙体、设施、坐标点 | 通道、路线、尺寸线、引线 | 单位、投影、比例、实测与示意区分 |
| 生物/化学 | 实体池、过程、原子、化学键 | 物质转换、调节、键级各异 | 价态与守恒；假说关系标注；机制需要来源 |
| 数据图表 | 位置、长度、面积、角度等数据标记 | 趋势线、区间、参考线、流量带 | 量纲、基线、图例和缺失值；形状不是随意图标 |
| 商业与质量 | 目标、因素、证据、任务、关系强度 | 分解、影响、逻辑、责任、价值流 | 候选原因不等于根因；关联不等于因果 |

## 风格覆盖的边界

暖灰背景、字体、留白、边框和强调色可以统一；符号几何、箭头方向、坐标尺度、图层语义不能为风格而改变。品牌图标若有原厂使用约定，保留约定形态或选用明确命名的中性节点。

正文深灰，次要说明中灰；重点可用锈棕；多系列优先线型、标记、直接标签及分面。不把所有边涂成相同颜色后丢失类型，也不把红绿状态变成唯一识别手段。

## 自定义元件的记录

建立新元件时记录：稳定 ID、含义、输入输出端口、默认尺寸、可伸缩范围、标签位置、连接规则、来源及授权信息、至少一个正例和一个误用反例。矩形替代符号只能称概念示意。没有读取正式标准全文或没有专用校验器时如实记录。

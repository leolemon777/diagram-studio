# 计划与报告图表

本批次覆盖仪表图、报告表、销售表格、日程和项目日历。五类图共享暖灰版式，但语义检查彼此独立。

- 仪表图必须给出上下限、当前值、目标、好坏方向、连续阈值区间和每段依据。颜色只辅助阅读，达标状态仍用文字说明。
- 报告表把明细与汇总分开；数值列必须声明单位，汇总函数只作用于明细记录。
- 销售表格把订单数、销量和销售额分列；区域小计从叶级记录计算，总计不再次累加小计。
- 日程声明时区，活动给出完整开始与结束时间；按负责人检查重叠和间隙，冲突在图中用红色显示。
- 项目日历用真实年月计算星期和天数；跨天事件逐日显示，并检查同一资源的日期重叠。

示例全部使用模拟数据。渲染器检查输入和计算一致性，不证明阈值、销售记录、排程或项目计划已在现场批准。

python scripts/planning_report.py assets/planning-report-models/equipment-availability-gauge.json --out output

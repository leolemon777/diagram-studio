# 战略与市场分析图

本批次覆盖市场分析图、产品策划画布、策略分析画布、竞争分析和力场分析。五类图共享克制的暖灰版式，但不能用同一张装饰性矩阵互相替代。

- 市场分析图必须声明市场范围和时点，坐标轴含义明确，并把有证据的观察与待验证假设分开。
- 产品策划画布保持问题、假设、实验和功能四层分离；每个假设都要有实验，每项功能都要回指假设。
- 策略分析画布要求证据支撑选择，每个选择写出放弃项，每项行动有责任人和衡量指标。
- 竞争分析使用同一范围、日期和评分量表；维度给出方向、权重和依据，低优维度在归一化时反向处理。
- 力场分析明确驱动力与阻力；只有全部因素都采用同一评分规则时，箭头粗细才编码力度。

示例全部使用模拟数据。渲染器验证模型和计算一致性，不证明市场判断、产品承诺、战略目标或竞争评分已经获得业务批准。

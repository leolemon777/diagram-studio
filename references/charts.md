# 数据图表与看板

先保留原始数据、单位、统计区间、来源、缺失值和分母。没有数据时，用明确标注的演示数据展示样式，不把假设数字作为事实。

| 问题 | 优先图型 | 要点 |
|---|---|---|
| 排名与类别比较 | 横条、点图 | 有序排列；柱条数值轴从零开始；负值需双向轴 |
| 时间趋势 | 折线 | 真正日期间距；缺失不能默认补零；不要平滑出不存在的峰值 |
| 构成占比 | 堆叠条、百分比条、少类别环图 | 同一总体，分项互斥，合计有意义；负值不能做饼 |
| 分布与离群 | 直方、箱线、散点 | 分箱/分位计算必须可复算；样本量与异常处理说明 |
| 两变量关系 | 散点 | 同一个体成对观测，相关不等于因果 |
| 三个变量 | 气泡 | 面积对应数值，不能把半径直接当数值 |
| 多维得分 | 热力/点阵，必要时雷达 | 先统一可比尺度；雷达轴顺序不能故意夸大差异 |
| 指标达成 | 目标条、子弹图 | 实绩、目标、期间，避免无比较基础的大仪表 |
| 贡献与阶段转换 | 瀑布、漏斗 | 瀑布累积准确；漏斗同一批次/口径，不能暗示不存在的转化关系 |
| 地理差异 | 分级设色或地图点 | 先核对地理边界；数量与比例选择不同编码 |

## 视觉

只突出一个主要结论，直接标注优先于读者反复找图例。轻网格、统一小数与单位，拒绝用 3D 透视改变面积/高度。双轴慎用；不同尺度并列小图通常更清楚。图表标题不得先于分析编造结论。

用户要求 Lieflat 式精致数据表达时，按 [细读数据图配方](data-art.md) 把单位短线、逐日记录、面积点阵、原始样本与旁注落实到图形。`data_art.py` 有12类工业样例配方、细读/快读模式与原七色；关键数值先计算再撰写说明，不能只换背景或补装饰纹理。

## 本地生成器范围

通用矢量生成器包含条形、折线、面积、散点、气泡、直方、热力、瀑布、矩形树等模式，具体输入见 extended-layouts.md。科研后端 scientific_plot.py 已实现28种模式，其中本轮24种见 [科研图表方法与输入](scientific-atlas.md)。

科研表格优先保存数值精度、分母、重复次数和缺失。三线表按真实观测计算均值/SD与分位数；消融表展示实际重复运行的均值/SD，最优数值不自动意味着统计显著。两类同时导出CSV。

## 验收

从源数据独立计算至少一个关键值和图中比例；检查轴范围、单位、合计、四舍五入、缺失和分母。看板每张图都应能回答一个问题，不堆“装饰性数据”。

## 能源与运行分析

指数、环比、同比、跨年季节叠线、年内累计、单耗、目标偏差、日历热力、负荷持续、后向均值、累计目标偏差和前后哑铃图见 [能源与运行分析](energy-atlas.md)。12 套配方使用 energy_plot.py；输入值、零分母、缺失、月度量和表读数先核对。

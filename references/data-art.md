# 数据图形的细读表达

适用于用户希望落实 Lieflat Charts 的数据标记、细密刻度、文字层次和旁注编排，或要求有编辑质感的产线、能源、统计数据图。与六套结构图家族互补：数据图使用本文件；鱼骨、架构、流程仍走 `style-families.md`，不能把点阵纹理当作其新增关系。

v54 起，前后哑铃配方提供中英跨行业样例（`dumbbell-cn.json` / `dumbbell-en.json`）。输入可选 `language: "zh"` 或 `"en"`；英文版会同步本地化图内读图约定、观察、边界、来源标记和配方标题，长对象名按词边界换行。v55 又补充同一语言约定的瀑布图样例（`waterfall-cn.json` / `waterfall-en.json`），并保留基期、期末、符号变化和计量刻度。其他配方仍应逐项检查叙事文案是否适合语言和领域，不因这两种配方的双语覆盖而外推。

## 选型

先判断要比较什么，再选数据编码；“精美”不改变数值含义。

| 配方 | 输入和容量 | 细读模式 `detail` | 快读模式 `clear` | 关键边界 |
|---|---|---|---|---|
| `rungs` 刻度柱 | ≤8 类，非负值，明确 `quantum` | 单位短线、精确顶端、余量短线 | 从零起的实体柱 | 太密时增大注明的计量单位；不取整吞掉余量 |
| `barcode` 日序条码 | 2–180 个严格升序 ISO 日期，允许 null | 逐日细杆、空心周末、相邻折线 | 较强折线与观测点 | 横坐标按时间间隔；null 断线，不能补零 |
| `area` 细线面积 | 2–120 个升序时刻，允许 null | 单时刻负荷形成细线轮廓 | 加强采样线与外轮廓 | 功率不能直接求和当电量；缺测不连线 |
| `ring` 计量环 | ≤6 个互斥分项，正合计，`quantum` | 刻度计量、部分刻度、精确分界 | 比例圆弧 | 这是数量与占比，不是个体事件；相近分项优先用条形 |
| `field` 计数点阵 | ≤3 类，整数，合计 1–200 | 每点一个计数单位 | 百分比堆叠条 | 聚合计数不是逐个样本身份，不能虚构样本 ID |
| `dumbbell` 前后哑铃 | ≤7 组 `before/after` 同单位非负数据 | 空实端点、细线、两端数值 | 强调变化线段 | 同实体成对；前值为零时百分比变化未定义 |
| `scatter` 垂线散点 | 2–100 组成对数值，x/y 单位 | 点＋回读横轴的垂线 | 清楚的等大点 | 点大小无第三变量；相关不等于因果；常量轴相关系数未定义 |
| `matrix` 面积点阵 | ≤12 列 × ≤6 行，≤80 格 | 空心圆、克制网格 | 实心圆与可容纳的数值 | 圆面积正比于值；缺测用 ×，零值独立标记 |
| `distribution` 样本与箱线 | ≤5 组，每组 2–150 个原始测量 | 原始点＋箱线 | 箱体、中位数、离群点 | 分位数线性插值，须线到 1.5IQR 内实测极值；不删除离群值 |
| `waterfall` 增减分解 | 非负基期＋≤7 个带符号变化，`quantum` | 按单位绘制浮动短线 | 浮动实体柱 | 期末=基期+变化；允许累计值转负，纵轴必须容纳 |
| `multiples` 指数小多图 | ≤4 序列，各 2–48 期，共同日期 | 逐期标记与观察线 | 清楚折线 | 每条首期>0；除以各自首期×100；共用轴范围，不比较绝对量 |
| `parallel` 多维剖面 | ≤6 实体 × 3–6 维度，固定轴范围 | 独立轴、细路径、空实点 | 加强路径 | 各轴保留量纲；不把路径面积或平均分当综合评分 |

这些是工业示例配方，不是任意字段的完全自动解释器。用于其他领域时，先核对生成器的旁注、KPI 名称与单位是否仍适用，并同步修改叙事。不要把“产能”“节能”“停机”等示例语义套到无关数据上。超出容量时拆成多图或采用现有科研后端，不能截断数据。

## 可复用的视觉规则

- 默认沿用用户选择的暖灰底 `#F1EFEB`。仍可用 `warm/blue/sage/sand/lilac/charcoal/mono` 原七色；当前图册展示 warm、blue、charcoal。色板和阅读模式变化不改变输入或统计结果。
- 1600×1000 图版中：49px 常规宋体标题、21px 说明、17–20px 轴/分类/旁注、60px 关键值、14px 等宽索引。正文、次级说明、强调数字分别使用 ink/muted/accent。图内数值用无衬线字体，避免用强调色铺满整页。
- 图形区域优先，右侧留一列放一个可复算指标、观察和解释边界。图下用一句话写清“一个标记代表什么”。来源、期间、单位、模拟标记随图保存，不依赖口头补充。
- 辅线约 0.6–0.8px，观测/关系线约 1–2px，快读主线约 3–6px；基于画布尺寸重新评估。细线仍要有对比，不把主数据变成看不见的淡灰。
- 视觉纹理来自有效记录或明确数量单位。不能随机补点、抖动数值、伪造缺测、添加无对应关系的连接。分布图只在横向错开重合点，纵向保留原数值。
- 用刻度而不是实体柱时，先选择可解释的单位。余量按部分线长保留；图注明确完整刻度单位。环境网格可以丰富阅读参照，但不能伪装成数据。
- `detail` 面向逐条阅读；`clear` 面向快速比较。并非每种结构都要彻底变形：哑铃、平行坐标保留原结构，改变线宽和标记密度即可。复杂图不要为了所谓高级感改成不适合的径向图。

## 执行

横屏/竖屏/方形和自定义像素的参数见 [画布尺寸与排版](canvas-sizing.md)。它们不改变数据或统计值；切换竖屏会移动旁注，并对绘图区重新排版。

读取命中的一份 `assets/data-art-examples/<recipe>.json`，替换数据、标题、说明、单位、来源与期间。`synthetic` 必须显式为布尔值；没有实测数据时为 true。保持每行唯一 `id` 和 `label`。

```bash
python3 <skill-dir>/scripts/data_art.py brief.json \
  --out <output-dir> --mode detail --theme warm
```

`--vector-only` 只需 Python 标准库，生成 SVG、draw.io、场景、输入、分析、QA、CSV 和单文件 HTML。默认另用 Matplotlib/fontTools 生成 PNG/PDF；系统需可用中文字体。`style_family.py` 是同包的共享导出器，不依赖参考仓库。不会联网调用三个参考项目。

每个 JSON 的公共字段：

```json
{
  "recipe": "rungs",
  "title": "同一工况的产能比较",
  "subtitle": "统计口径和观察窗口说明",
  "unit": "件 / h",
  "period": "2026 年 6 月",
  "source": "明确的数据来源",
  "synthetic": true,
  "quantum": 20,
  "rows": [{"id": "line-a", "label": "产线 A", "value": 785}]
}
```

其他配方差异：

- barcode/area：行增加 `date`（ISO 日期或日期时间），`value:null` 明示缺测。
- dumbbell：用 `before/after` 替代 value。
- scatter：行用 `x/y`；公共层提供 `x_label/y_label/x_unit/y_unit`。
- matrix：公共 `columns/groups` 列表；行含 `column/group/value`，每个交叉单元恰好一次，未知用 null。
- distribution：每行 `values` 原始测量数组。
- waterfall：公共 `start`，行 value 为增减值。
- multiples：公共 `dates`；每行 `values` 与日期一一对应，并有自身 `unit`。
- parallel：公共 `dimensions`，每维 `id/label/unit/min/max`；行 `values` 是按维 ID 索引的对象。

单文件 HTML 内嵌 SVG、原始数据、CSV 和 draw.io 源；浏览器打开可查询标记、展开数据、下载源文件。修改图形文字不会自动修改测量数值；要保持比例与统计一致，改输入后重绘。SVG/draw.io 不依赖网页截图；draw.io 的可编辑对象是形状和文字，不是有公式联动的电子表格。

## 提示词任务块

> 根据需求「{需求}」先识别比较、趋势、构成、分布或关系；从 data-art.md 选择符合数据语义的一种配方。用用户定义的色板，保留中文字体、数值、说明与来源的层级。若需要细读，标记对应实际观测或有明确单位的数量；若需要快读，用同一数据绘制更清楚的轮廓。先计算关键值，再写观察旁注。保留原始单位、时间间距、缺测与分母。输出 SVG、可编辑源、数据和单文件 HTML，打开实际成图检查文字与数据。示例数据明确标注，不把样例结论当现场事实。

针对常见请求：

- “水电耗更精致”：原始月耗用分图；比较节约幅度用 multiples，输入真实单耗后归一；日耗细节用 barcode，半小时负荷用 area。不要未经说明叠加双轴。
- “产能提升分析”：类别产出用 rungs，前后单耗用 dumbbell，节拍样本用 distribution，耗电构成用 ring，增减核算用 waterfall。原因分析仍用鱼骨，不用数据图编造因果。
- “科研效果”：原始样本与箱线优先 distribution；必须推断统计、置信区间、显著性时调用现有 scientific_plot.py，不能用美术处理替代统计计算。

## 检查与当前边界

至少独立复算一个关键值；同一输入在不同配色、模式下分析结果必须完全一致。检查部分刻度、百分比总和、面积开方、缺测断线、零分母和负累计值。`qa.json` 的画布边界通过不等于文字或编辑器验收。

图册有 12 配方 × 2 阅读模式 × 3 预览配色，属于 72 个呈现变体，不是 72 种新图型。原326条类型入口不因此全部完成。网络/流向交互、地图、完整报告、动画、Lieflat 的其他统计变体仍按具体任务研究，不声称本轮已复刻原项目全部能力。

# 运营与精益分析配方

这里补充 9 套可计算、可重绘的业务组合。查看对应 `assets/operations-examples/<mode>.json` 获得完整输入结构，不必把全部示例载入上下文。

```bash
python3 <skill-dir>/scripts/operations_plot.py input.json --out output --theme warm
```

依赖 Matplotlib、NumPy；计算函数 `analyze` 不绘图。生成 SVG、PNG、PDF、输入 JSON、计算 JSON 和排版检查 JSON。SIPOC 与 VSM 另有原生节点 draw.io 和 scene JSON。统计图的可编辑源为 JSON 与脚本；SVG 文字能否在其他编辑器内逐项编辑取决于实际导入效果。

| mode | 适用与输入 | 计算/语义约束 | 已实现边界 |
|---|---|---|---|
| oee | 设备效率；periods 含计划分钟、停机分钟、理想周期秒、总数、一次合格数 | A=运行/计划；P=理想周期×总数/运行；Q=一次合格/总数；统一秒分钟 | 1–4 期；拒绝性能>100%、合格>总数；无产出/全停机情况需另行解释，当前拒绝 |
| balance | 串行单件流工位；净可用秒、需求件数、stations 周期秒 | 节拍=净可用时间/需求；稳态理想上限=floor(时间/瓶颈周期) | 2–10 工位；每工位一个等效作业资源，不处理并联设备、混流、故障模拟 |
| control_imr | 按时间顺序单个连续测量值，单位、baseline_count | 相邻极差估计变异；仅基线估限，后续沿用；控制限不是规格限 | 8–120 点；8 点是演示下限，不是稳定基线充分性保证；只识别三西格玛越界，不检测全部运行规则 |
| vsm | 产品族当前态/未来态、供应商客户、信息流、2–5 工序及 CT/等待/库存 | 物料实线、信息虚线；等待和加工时间分开，统一分钟汇总 | 简化串行流；明确时间轴不按长度比例；加工时间不自动当增值时间；无完整精益符号库 |
| sipoc | 明确起止边界；S/I/P/O/C 五列各1–6项 | 输出与客户需求逐行对应，其余列不强行逐行配对 | 高层范围说明，不代替详细流程 |
| sales_review | 2–12 连续月份，actual/target、区域与产品销售额、单位 | 两组分类分别与期间实际销售总额对账；达成率=sum实际/sum目标 | 非负销售收入；退货净负收入、跨币种须另行扩展 |
| sales_funnel | 同批对象定义 cohort；2–7 个阶段人数 | 相邻转化与整体转化分开；阶段人数单调不增；0分母不显示成0% | 逐级嵌套漏斗；不用于跨期活动量或可回退状态计数 |
| inventory_review | 物料单位及期初/出入/期末、期间成本与平均库存成本、账龄 | 数量结存逐项对账；成本账龄对期末；周转用销货成本；天数用指定期间长度 | 1–8 物料；平均库存成本为输入，不由缺失日余额臆算；账龄按成本，不跨单位合计数量 |
| energy_review | 同期水/电消耗、月产量、明确单位 | 总量和单耗分面；总量/有效同期产量计算加权单耗 | 1–2 资源；缺失/null 与0区分，排除不可算月份；不把 m³ 与 kWh 相加 |

所有输入必须有 `title`、`mode`、`data_status`，推荐加 `subtitle`、`assumptions`、`footnote`。示例明确使用模拟数据。换真实数据时必须同步改来源声明，不能只替换标题。

## 选型与对比结果

| 任务 | 采用方法与原因 | 当前不采用的替代方法 |
|---|---|---|
| 产能改善 | 先工位平衡找瓶颈，再OEE解释时间损失；鱼骨用于待验证原因 | 不把鱼骨分支数量换算成收益，不直接加总改善百分比 |
| 波动判断 | I–MR适用于单个连续观测；数据结构不同再改图型 | 不能把任意数据都套入 I–MR；计数/比例需p、u等模型 |
| 价值流 | 信息流、物料流、过程数据、等待时间一起看 | 单一流程箭头缺少库存与时间，无法承担同样分析任务 |
| 销售转化 | 等高横条+人数+转化率便于数值比较 | 避免漏斗面积和宽度混用导致比例错觉 |
| 综合能耗 | 统一月份，分开单位，配合单位产量消耗 | 双轴可制造虚假相关；总耗下降也不能直接断言效率提升 |

## 专用提示词

- OEE：从原始时间和计数计算 A/P/Q/OEE，核验单位与一次合格定义，展示时间损失分解。前后对比只描述演示差异，不能称为因果效果。
- 工位平衡：先询明或声明并行资源和工作制度；明确净可用时间与需求节拍；标出超过节拍工位及瓶颈。展示的是稳态理想上限。
- 控制图：确认连续测量、时间顺序、独立性与基线；只使用指定基线估计控制限；标注监测阶段和检测规则，不把控制限称质量合格范围。
- VSM：先选一个产品族和一个状态；明确每段等待、库存与加工周期；物料和信息分层；按统一时间口径汇总，不能把观察值写成现场实测。
- SIPOC：先界定开始与结束；列供应者、输入要求、关键过程、输出、客户要求；检查每个输出的接收者和要求。
- 销售：确认时间和收入口径；区域/产品分组分别与总额对账；比较实际与目标，标出单位和缺口。
- 漏斗：固定同批对象与截止日，验证阶段嵌套，再分别显示相邻和整体转化；不能拿不同月份人数拼漏斗。
- 库存：逐物料验证结存公式；成本周转和数量台账分开；说明平均成本库存、销货成本和期间天数来源。
- 能源：保留缺失与零产量；按资源分别画总量和单耗；输出有效月份与排除月份，不声称单耗变化本身证明措施有效。

## 方法来源与覆盖

公开目录用于发现类型，以下一手方法来源用于校核计算。这里的实现、输入约束和视觉选择为原创整理；不声称复刻全部软件模板或通过标准认证。

- [Vorne / OEE 计算](https://www.oee.com/calculating-oee/)：A/P/Q及一次合格定义。
- [NIST 单值控制图](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm)：相邻极差、d2=1.128和I图界限。
- [Minitab 移动极差方法](https://support.minitab.com/en-us/minitab/help-and-how-to/quality-and-process-improvement/control-charts/how-to/variables-charts-for-individuals/i-mr-chart/methods-and-formulas/methods-and-formulas-for-moving-range-chart/)：MR图平均极差法。二点极差使用D3=0、D4=3.267。
- [Lean Enterprise Institute 节拍](https://www.lean.org/lexicon-terms/takt-time/)及[价值流](https://www.lean.org/lexicon-terms/value-stream-mapping/)：需求节拍、物料流/信息流及当前态/未来态。
- [ASQ SIPOC](https://asq.org/quality-resources/articles/sipoc-job-aid?id=232019f796fc447dad7cdb2cf242f48a)：高层过程边界及五类要素。
- 销售与库存采用明确写出的算术/记账恒等式；当前没有接入ERP、做财务审计或实施动态库存优化。

Xbar-R/p/np/c/u基础配方已另见[控制图方法](spc.md)，包含冻结基线与变分母。仍缺：完整VSM符号、控制图高级变体、混流平衡、完整财务报表以及其他行业看板。七主题样张不等于新增63类图型。

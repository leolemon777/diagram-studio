# 多来源择优规则

这里的选择是对公开能力、表达语义与任务约束的综合判断，不是跨软件跑分。参考软件提供结构灵感；规范决定语义；真实输入决定内容；用户决定风格。

## 选择优先级

先判断图能否正确表达事实，其次判断目标读者能否读懂，再判断源文件是否便于修改和复算，最后优化视觉。不能因为某个渲染器已安装就把不适合的图型硬塞进去，也不为了形式新颖采用难比较的编码。

| 任务 | 万兴方案中值得保留 | 其他资源更有优势的部分 | 本 Skill 取舍 |
|---|---|---|---|
| 系统架构 | 模块、分层与容器的可视组织 | C4 的视图分级和责任描述 | 先上下文/容器，再选择分层或依赖布局；部署另图 |
| 企业架构 | 业务与技术全景 | ArchiMate 的元素、视点、关系体系 | 正式模型按指定版本；领导概览用少量能力域及关键映射 |
| 大型有向图 | 手工控制节点位置 | Graphviz dot、ELK 分层和端口布局 | 先算法布局，后统一暖灰主题；跨层边多时拆图 |
| 关系网络 | 丰富节点图形 | 力导向、聚类和矩阵表达 | 社群关系可力导向；需要查精确关系时采用矩阵 |
| 工作流程 | 流程与泳道模板 | Mermaid 文本维护；BPMN 正式过程模型 | 普通流程选轻量源；跨池、事件、网关选 BPMN XML |
| 软件建模 | UML 图形入口 | OMG 语义与 PlantUML 文本源 | 按图型核对关系；简单样例和完整标准支持分开标明 |
| 云架构 | 云图标集中可用 | AWS/Azure/GCP 官方图标与产品文档 | 从官方当前符号取用；逻辑边界不由图标排布替代 |
| 数据库 | Chen、乌鸦脚等多记法 | DDL 驱动与约束信息 | 概念教学用 Chen；物理库优先从 DDL 导出乌鸦脚 |
| 科研统计 | 易于排版和注释 | Matplotlib 可复算数据与标准图型 | 统计结果由计算产生；保存数据、脚本、SVG/PDF |
| 交互数据图 | 仪表与图表组合 | Vega-Lite 的声明式编码与分面 | 分析任务需要筛选时采用交互；静态汇报保持简洁 |
| 类别比较 | 柱、条、饼和雷达 | 数据可视化研究中的长度比较原则 | 精确比较选条/点；组成且类别少才用饼；雷达用于轮廓 |
| 指标达成 | 半圆与圆形仪表 | 子弹图的紧凑比较 | 多指标优先子弹图；单一仪表需求可保留真实阈值 |
| 多集合交集 | 韦恩视觉直观 | UpSet 对较多集合的可读性 | 两三集用韦恩；更多集合或精确计数优先 UpSet |
| 地理与方向 | 直观方向图、地铁图 | QGIS 的地理数据、投影与地图布局 | 路线拓扑可简化；真实边界和距离使用地理数据 |
| 电气工程 | 多种元件符号入口 | KiCad 网表、连接检查、ERC | 教学图可用 Schemdraw；实施图在专业工具校核 |
| 工艺过程 | PFD/P&ID 专门符号分类 | ISA/项目标准的位号与信号约定 | PFD 与 P&ID 分开；正式图必须保留管线和回路信息 |
| 分子/生物 | 教学素材组织 | RDKit 的化学结构；SBGN 的过程符号 | 结构数据优先；不以通用箭头和装饰模型冒充科学机制 |
| 质量改善 | 鱼骨、质量屋、价值流、七工具 | ASQ 的问题分类与 LEI 的物料/信息流方法 | 按问题选工具；候选原因、实测数据、改善目标分别标注 |
| 计划排程 | 甘特、PERT、日历、看板 | 依赖网络计算与日期模型 | 精确排期可计算；方向规划用路线图，状态流用看板 |
| 商业画布 | 一页组织复杂信息 | Strategyzer 的构件关系及验证思想 | 先选模型，再填真实信息；假设显式标记并关联验证 |
| 信息图与卡片 | 主题覆盖和模块组合 | 清楚的视觉层级与必要对比度 | 内容驱动网格；主题不强制多色；沿用 #F1EFEB |

## 处理资源冲突

- 模板与正式语义冲突：采用规范，并记录修正；模板标题不构成语义证据。
- 不同规范版本冲突：保存用户指定版本；没有指定时核对当前任务的交换/工具兼容要求。SysML v1 图不能改名宣称 v2。
- 图标品牌规则与主题冲突：保留受约束图标本体，用背景、文字、边框统一风格；也可改用清晰命名的中性节点。
- 展示与可编辑性冲突：保留领域源文件及数据，SVG 作展示。SVG 并不保证导入任意软件后仍有同等编辑语义。
- 标准全文或素材不可访问：保留入口与限制；只对实际读取部分给证据。按需使用已核实语法，不能用“全量”掩盖缺口。

## 后端使用约定

`local-vector` 为本 Skill 实际附带的离线生成器，现有样例见 library-index。其他名称是择优路线，不代表已安装对应工具。使用时先检查可用版本，再按官方文档输出源文件并实际渲染。

需要特定专业语义但工具未安装时，当前助手可依据该条目的规则直接编写可编辑 SVG/draw.io 或领域源码，检查产物并明确验证范围。没有运行专用验证器时，不得把通用矢量示意称为标准认证或工程可实施模型。

完整来源及访问记录见 [source-comparison.md](source-comparison.md)。选择具体类型用 `scripts/knowledge.py`；不要一次把整个库加载到上下文。

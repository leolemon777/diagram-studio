# 万兴图示研究记录

日期：2026-09-16。方法：Mac 桌面端 Computer Use、官网模板社区浏览器自动化、官方帮助页；没有反编译、读取私有算法/提示词、批量搬运付费模板或素材。

## 证据级别

- 目录观察：官网九大类和已展开的子类别，见 catalog.md。
- 原生视觉观察：本机实际打开/整页查看的七种样本，见下表。
- 原创实现：本 Skill 的规则、提示词、配色与生成脚本。
- 待验证：其他模板、全部专用符号、全部导出格式、所有正式标准和全部软件功能；不能称“全量蒸馏完成”。

## 原生样本与设计提炼

| 实际打开的样本 | 观察 | 提炼与改进 |
|---|---|---|
| 系统架构通用模板 | 展现/通讯/服务/数据横层；服务层嵌套；蓝紫框；密集技术名词 | 保留层次与横向支撑；减少厚框和技术清单；增加关系含义与主路径 |
| 跨职能流程图 | 文件名如此，但实际画布标题“手绘风格流程图”，无泳道；图例含开始/过程/判定/文档 | 模板名不能作为语义证据；检查真正画布；泳道另按责任语义生成 |
| 工业控制系统 | 动力/控制回路、元件位号、连接点和图签；设备专用符号库 | 工程语义先于美化，概念架构与电路原理不能混为一谈 |
| 项目时间规划进度工作汇报甘特图 | 左侧任务/日期/持续/进度表，右侧日历条；多色进度 | 日期与条宽联动，进度与类别色区分，核对图例 |
| 用户登录时序图 | 人员/对象、竖向生命线、激活条、编号消息、虚线返回 | 时间向下，回复与请求区分，复杂交互分片段 |
| 基本企业组织架构图 | 横向多层树；分支分色；大量细小文字 | 分支继承色，按阅读尺寸拆图，不把全树压成不可读小字 |
| Java知识图谱 | 中心两侧彩色曲线分支；多级节点；画布上部空白较大 | 按内容适配画布，控制分支密度，长文字采用方向统一的树 |

另尝试“公司岗位层级架构图”出现高版本创建提示，取消打开；未将它计作原生验证。观察到设计栏有一键美化、颜色/连接线/文本主题、背景、自动扩展、页面适配、跳线、单位等。导出对话框列出图片、PDF、Word、Excel、PPT、GIF、SVG/EMF、HTML、Visio、CAD；只确认入口，没有声称每种已成功导出。

## 研究得到的完整工作链

需求 → 图型 → 数据/关系 → 标准符号 → 容器与层次 → 布局/连线 → 主题/文本 → 页面适配 → 源文件与导出 → 重开验证。技能覆盖这条链；不等于实现万兴桌面产品的所有交互、海量符号或全部专业编辑器。

## 第二轮：结构扩展

用户指出仍有很多图表结构后，继续核对官方基本绘图、商务和分析画布子目录。基本绘图列出箭头、2D 框图、圆辐、圆形、列表、韦恩、知识地图；商务包含时间线、企业架构、关系矩阵、目标图、线路图、消费者旅程等；分析画布包含商业分析、产品策划、项目进度、策略、团队、终身学习。来源：

- https://www.edrawmax.cn/templates/1040/1/0
- https://www.edrawmax.cn/templates/1041/1/0
- https://www.edrawmax.cn/templates/1043/1/0

独立扩展到 60 个结构范例、26 个生成 type。这里的九个“用途分组”是我们重新组织的检索分类，和万兴官网九个产品分类并非一一同名对应。新增结构是原创实现，没有把官网缩略图下载成我们的模板。

用户色块主色和中心像素均为 #F1EFEB；默认底色已据此调整。这是当前任务明确选择，不是从历史记忆推断的审美。

35个资源入口与访问范围见 source-comparison.md；方法比较见 selection-playbook.md。主要结合OMG、C4、图布局与科研绘图库、云厂商、工程/科学专用工具。来源对比是方法适配判断，不是产品全功能实测排名。ArchiMate公开概览页面仍描述3.1，而本机符号库列出3.2，不能把该概览当作3.2完整核对证据。

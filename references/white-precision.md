# 纯白精研：白底上的字、线和数据

用户要纯白背景、通用报告、干净的科研/商业图版，或希望在白底上提升精致度时使用。底色为真正的 `#FFFFFF`，不替换已保留的暖纸、彩色或深色主题。单独另存版本，成图后让用户比较。

色值和字级角色见 `assets/white-precision.json`。不把风格简化成换背景；先确保结构与图型正确，再设计阅读顺序。白底的层次主要来自文字、线宽、对齐、留白和数据标记。

## 排版规则

- 标题用中文宋体常规字重；说明和节点用清楚的黑体。标题以简短、准确为先。中文与拉丁数字分别检查实际字体，不靠 CSS 字体名假定匹配。
- 大指标使用无衬线数字与较强字重，正文保留常规字重；多列数字用等宽或表格数字。完整名称、单位、时期和口径要能找到。
- 以 1920×1080 为参考：标题 52 px，说明约 20 px，正文/节点约 21–23 px，注释 15–18 px；密集网络的节点序号可用 13 px。4K 输出同比放大，而不是只改 PNG 分辨率元数据。
- 标题、正文、注释使用石墨和蓝灰三个层级；主数据用蓝墨。只在第二组确有语义时加入暖棕，数值正负保留符号。不能用颜色暗示不存在的统计显著性或业务好坏。
- 小字避免过轻灰色。四种文字角色对底色和浅填充分别计算对比度；当前白版最低约 5:1。还必须实际看缩小后的成图。
- 关系线、节点边框、辅助网格分开。网格很轻；主要数据与路径清楚；密集网络的非聚焦边可以弱化。没有信息作用的排线、阴影和装饰可以删减。

## 按图型精修

| 图型 | 在白底上优先处理 |
|---|---|
| 趋势与目标 | 实际线较强，目标用虚线和空心标记；保留单位、零基线、逐点数值或明确图例 |
| 漏斗与排名 | 统一零起点和长度尺度，等高横条，数值列对齐；减少密集装饰纹理 |
| 瀑布 | 总量与浮动增减分开；累计承接清楚；正负有符号，保持长度和位置编码 |
| 架构与流程 | 节点标题强于职责说明；边界明确；主调用与反馈分主次；标签避开线段 |
| 鱼骨 | 大类与原因分字级；主骨、分支、原因线有三级线宽；不让线穿字 |
| 甘特 | 日期与持续时间同尺度，条内文字可读，依赖箭头不穿过任务文字 |
| 分布 | 样本点、轮廓、中位数分别可辨；保留样本量、单位及带宽说明 |
| 相关矩阵 | 正负号、面积大小、数值和图例一致；不要写死不适用的色名 |
| 三线/消融表 | 列标题与数字列共享对齐位置；小数精度、误差表示统一；最优值从数据计算 |
| 神经网络 | 层级、节点、聚焦连接优先；上下文连接轻而可见；权重正负保留线型 |

## 十二图版重绘工具

```bash
python3 <skill-dir>/scripts/white_plate.py <source-dir>/<stem> --out <output-dir>
```

输入是对应的 `.scene.json`、`.input.json`，有统计结果时同时提供 `.analysis.json`。输出包含 PNG、PDF、SVG、draw.io、场景与 QA JSON。`--vector-only` 跳过 PNG/PDF。保留语义数据、统计结果、节点与边；调整字级、字重、线宽和部分标记填充，删除指定的非语义排线。

脚本当前明确支持分享图册的 12 种固定结构及 3840×2160 源场景；拒绝静默套用到其他图型或比例。其他后端可以采用该色板与上述设计规则，但必须按自身模型重新排版并检查，不能直接伪装成已验证适配。

## 验收与提示词

1. 检查数据、统计结果、正负号、节点和边是否与输入一致，定量图形的宽度/位置有没有被美化改变。
2. 查看实际 PNG：全图、表格密集区、交叉连线、最小文字。查看 RGB 背景确为纯白；SVG 背景也须显式写白，避免透明输出在其他背景上失真。
3. 与已有主题比较时，保持原数据与分析；说明白版还调整了字体与标记，不能声称它只是换色。
4. 逐项区分已生成、已检查和用户已认可。文件数量与格式校验不能替代观感验收。

可用提示块：

> 将需求绘制为纯白精研图版。先选正确图型，确认数据/关系与假设。用 #FFFFFF、石墨文字、蓝墨主数据；设置标题、正文、数字、注释的阅读层级，按图型精修标记、线宽和对齐。保留正负、单位、刻度、统计口径与结构语义。生成独立版本，保留旧主题。输出矢量与真实高分辨率图片，重新打开检查，报告实际验证范围。

# 视觉系统：用户定义，结构独立

用户在本任务明确要求：风格由用户定义，具有科研感和 Claude 风格，避免五颜六色。本次将它解释为暖白纸感、深灰墨色、少量陶土强调、充足留白与清楚的图注。以下是原创实现参数，不声称是 Claude 官方设计规范；用户随后提供色块并明确喜欢该底色：主色与中心像素均为 RGB(241,239,235)，即 #F1EFEB，现作为默认画布色。其他视觉细节仍需用户评价。

## 接受风格要求

先保留用户给定的配色、参考图、字体、线条、密度和用途。风格要求缺项时使用本次默认，不必重复询问。新的要求优先于下表；语义、关系与数据不随主题变化。风格参数和图型知识分别存放，禁止以“科研风格”为理由给业务图虚构实验结果、误差线或学术背书。

| Token | light 暖白科研（当前默认） | dark 深色阅读 | mono 黑白论文 |
|---|---|---|---|
| 画布 | #F1EFEB | #252522 | #FFFFFF |
| 面板 | #FEFDF9 | #302F2B | #FFFFFF |
| 主文字 | #30302D | #ECE8DE | #242424 |
| 次文字 | #6D6A63 | #B6B1A7 | #626262 |
| 细边框 | #D8D3C8 | #57534B | #CECECE |
| 主强调 | #AC6046 | #D39577 | #353535 |
| 辅助中性 | #67685E | #B6B6A4 | #707070 |
| 第三明度 | #8C7964 | #B5A088 | #919191 |

三者是同一克制风格的显示与打印变体。仅在类别区分需要时增加中性色的明度变化。分类必须同时带文字，不能靠颜色辨认。传统 `teal` / `amber` / `red` 键仅为渲染器语义槽，不要求使用蓝绿、黄色和红色；此处统一映射为中性色。

## 版式

- 默认 1600 × 900，画布边距 64。顶端标题区 120，底端说明区 60；内容过多增高/拆图，不无限缩字。
- 标题 34–40，节点标题 20–24，节点说明 15–18，注释 14–16；面向大屏时节点正文提高到 24–28。
- 中文使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC 回退；英文与数字用同一体系。SVG 保留文字，不提前转轮廓。
- 间距取 8 的倍数；同类节点同宽，容器 padding 24–32，节点间距至少 24，连线通道至少 28。
- 容器用浅色面或细边线，层次最多三层。避免厚重嵌套框、满屏高饱和和多种阴影。
- 全图通常一个低饱和强调色，其他采用中性色和明度差。主路径以少量强调突出，其余关系保持灰线；用文字、编号、线型和位置承担主要区分。禁止彩虹分类、霓虹渐变、玻璃卡片和装饰性阴影。

## 线与形

- 结构容器与关系边分开。包含不等于调用，贴近不等于连接。
- 主流程 2.5–3，次关系 1.5–2；异步/返回/待确认可虚线，但含义必须明确。
- 正交线优先；不得穿过无关节点。回路放外围。分支线标签紧靠对应分支，不压箭头尖。
- 不把每个小框都画成卡片；标准图的菱形、生命线、基数、设备符号保留。
- 图标只在能帮助识别对象时添加。品牌图标要来自合法可用素材，不从参考模板批量提取再分发。

## 密度与层级

标题回答“这是什么”，副标题回答“范围和阅读方向”；正文只保留必要名称与一行责任说明。长技术清单移入图外说明。总览通常 8–18 个核心对象，超过并非禁止，但应考虑拆分。将 16:9 画布当作信息预算，不用字号解决所有拥挤。

## 可验证的改进目标

同样的事实信息：更少无意义重复、更少交叉线、更大的有效字号、更明确的主路径、完整的可编辑源；不凭自评宣称整体胜过整个万兴图示产品。

## 本项目的高级感与质感

用户进一步强调要高级感、质感，并关心原配色是否保留。新增设计另存，保留七套原配色及已有成图；六套风格家族另见 [style-families.md](style-families.md)。不能用配色数量替代视觉完成度，也不能把六家族与七配色说成十三套同等的新风格。

- 纸与墨的关系：默认以 #F1EFEB 为纸底，用深墨文字、略带冷暖差的中性色和小面积强调形成层次。浅底要温润清晰，深底要保持足够的文字与细线对比。
- 字体的精度：中文标题按语义分行，避免孤字、孤立标点和机械断词；正文保持易读，数字、单位、小数位与表格对齐。
- 构图的精度：为主图留足空间，题签、注释和来源各有位置；强弱有别，避免全页均匀铺满同样的小框。
- 线条的精度：主干、次关系、辅助线区分粗细；端点、箭头、连接与转折保持一致。小图放大后仍要干净，缩小后仍能辨认主次。
- 材质适量：纸感优先由底色、墨色、字体和留白建立。需要插画或材质时另作可选表现层，不能遮挡数据、改变标准符号或降低矢量输出的清晰度。
- 验收以成图为准：并排比较同一内容的方案，并查看完整尺寸。已生成且无越界仅说明技术检查通过；是否达到用户所说的高级感，仍以用户的实际视觉反馈为准。

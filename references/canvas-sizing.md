# 比例、像素与排版

用户要求横屏、竖屏、方形、自定义比例、分辨率或打印尺寸时读取。比例是宽高关系，像素是 PNG 的实际尺寸，DPI 决定这些像素对应的打印长度；三者不能混称。SVG/PDF 使用矢量对象，高像素导出必须从对象重新渲染。

## 当前实现

`style_family.py` 的鱼骨、架构、闭环流程、趋势四类图版，以及 `data_art.py` 的12类配方，支持相同的尺寸参数。六风格家族、原七配色仍可选择。不传尺寸参数时保留原1600×1000布局。

- `--width 1920 --height 1080`：实际像素大小，支持任意符合内容容量的宽高比。
- `--ratio 9:16 --long-edge 3840`：竖屏2160×3840。比值接受 `a:b` 或 `a/b`，计算后取整到像素。
- `--dpi 300`：打印密度，独立于像素；有明确画布时默认144 DPI。只指定DPI则保持原1600×1000构图。
- `--layout adaptive`：根据比例排版；窄画布流程纵向、鱼骨上下展开、架构分层，数据旁注下移，环/点阵与图例上下编排。字体、圆形标记保持形状，数据坐标按新绘图区重新映射。
- `--layout fit`：保留原布局，完整等比居中，剩余部分用主题背景填充。适合保留原图构图；不裁剪内容。

像素边长128–16000、总量不超过4000万像素，是当前本地导出的资源上限，不是设计推荐尺寸。低尺寸可能使文字不可读；画布QA记录小字号提示。特别狭长的画布使用完整居中或拆图，不能靠裁掉注释/节点伪装成适配。自适应并不保证任意长度文案、任意密度数据都无需调整；新增内容要重新看实际输出。

## 命令

```bash
python3 <skill-dir>/scripts/style_family.py brief.json \
  --family ledger --ratio 9:16 --long-edge 1920 --dpi 144 \
  --layout adaptive --out output/portrait

python3 <skill-dir>/scripts/data_art.py data.json \
  --theme warm --mode detail --width 3840 --height 2160 \
  --dpi 300 --out output/landscape-4k
```

新增 `.canvas.json` 保存尺寸、实际比例、DPI、排版模式和打印毫米尺寸。`.scene.json`、SVG画布与draw.io页面均使用实际宽高；输入数据和计算摘要不随尺寸改变。PNG记录DPI，PDF页面大小为 `宽或高 / DPI × 72` 点。A4的“比例”不自动等于A4打印尺寸：约2480×3508px配300DPI才接近210×297mm。

`--vector-only` 不依赖 Matplotlib；PNG/PDF依赖与原生成器相同。画布逻辑在同包的 `scripts/canvas_layout.py` 中，不依赖外部参考仓库。

## 可视化选择

```bash
python3 <skill-dir>/scripts/canvas_server.py --out <output-dir>/canvas --port 8767
```

打开 `http://127.0.0.1:8767/`。可选择图型、风格、横竖比例、长边像素、自定义宽高、锁定比例、交换宽高、DPI、排版方式，并下载SVG/draw.io/原始数据/尺寸参数或渲染PNG/PDF。界面当前加载Skill里的示例；真实数据通过上述CLI输入，不把示例当现场实测。

服务只监听本机回环地址，关闭进程后预览入口不可用，已导出的文件仍可使用。无安装常驻服务、开机任务或外部发布步骤。页面跟随服务提供，不能仅复制HTML后假定动态导出仍可用。

## 其他图表与专业工具

本轮自适应入口只覆盖上述四类结构图与12种数据配方，不代表326目录条目都实现了自动横竖排版。其他通用渲染器或科研后端先按自身布局规则构图，再设置实际尺寸并重新检查。不得直接拉伸截图、椭圆化圆形标记，或用提高DPI元数据代替提高像素。

检查至少包括：各格式实际宽高；内容没有缺失；关系端点仍连接同一对象；圆面积编码与统计值不变；字体/线宽等比随导出尺寸变化；低分辨率可读性；一个代表性源文件在编辑器中重开。网页适应窗口只是预览缩放，不能当作导出尺寸验证。

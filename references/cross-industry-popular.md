# 跨行业热门类型

本页对应 `assets/cross-industry-models/` 的 46 份输入和 `scripts/cross_industry.py`。它修正了先前偏工业的筛选，覆盖办公财务、招聘求职、教育教学、医疗健康、建筑家装、软件产品、科学科普、旅游交通、新闻传播和节庆营销。

## 选择原则

- 以跨行业使用频率、可复用性和专业价值为主，不以是否贴近工业现场判断。
- 主流设计与白板平台持续提供的简历、发票、证书、网站、信息图、学习组织器、原型和空间图优先。
- 同义或上位入口可以链接专用子类型，但必须有具体输入和对应证据等级；“有样例”不自动等于已人工验收。
- 只将过时、重复、季节过窄或高度专业且缺少广泛复用价值的入口保留为检索项。

## 七类验证模板

1. `graph`：家庭树、家系图、UML 总览与包图；核对节点、关系类型和端点。
2. `wireframe`：Windows、iPad 和网站概念原型；核对页面、内容区、跳转和响应式规则。
3. `spatial`：家居、景观、天花、立面和定制柜；核对分区、尺寸和画布边界。
4. `route`：公共场所导引；核对地点引用、路线连续性和距离声明。
5. `science`：分子、人体、生物和天文；核对概念、关系、来源字段和声明边界。当前输出是概念关系示意，不是解剖插图、分子结构制图或诊断依据。
6. `publication`：发票、简历、报销、报价、证书、卡片和行业信息图；核对角色、阅读顺序，财务文档另重算合计。
7. `organizer`：通用、主旨、词汇、比较、顺序、矩阵、写作和阅读组织器；核对学习目标、填写区、逻辑关系和完成标准。

## 重绘

```bash
python scripts/cross_industry.py assets/cross-industry-models/invoice.json --out ./out
```

真实使用必须替换模拟名称、事实、数值、尺寸、来源、品牌和审批信息。空间图不替代施工图；医疗和科学图不用于诊断；节庆内容需按受众和地区重新判断。财务出版物的行项目、税率和合计从同一输入计算，修改数据后必须重新生成，不能手改 SVG 中的金额。

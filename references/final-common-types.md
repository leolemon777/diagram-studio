# 最终常用类型

本页对应 `assets/remaining-type-models/` 的 33 份输入和 `scripts/remaining_types.py`。它提供常用、高价值和专业场景的精选输入，不代表整个目录均已由这一后端覆盖。示例数据均为教学模拟。

## 共同交付

- 每份模型输出 SVG、PNG、可编辑输入 JSON、计算摘要和 QA JSON。
- 先验证语义，再渲染；节点、边、区块、指标和来源标识均使用稳定 ID。
- 厂商服务名可作为数据标签；图中只使用中性矢量元素，不复制或捆绑厂商图标包。
- 平面出版物提供内容结构和阅读顺序，不代替真实品牌规范、印前处理、事实核对或审批。

## 系统、科学与专业图

- 电路与逻辑：输入必须包含电源、传感器、逻辑门和负载；示例真值表必须与 AND 逻辑逐行一致，且负载从电源路径可达。
- 系统图：先画系统边界，再列参与者与外部接口；命令、遥测和工单三类关系不得混写。
- 地铁/线路图：拓扑和站序优先，路线必须有稳定 ID，换乘站同时引用至少两条线路；明确“不按比例”。
- 地理地图：坐标必须在声明边界内并保留来源；示意位置和精确测绘必须明确区分。
- 数学：保留问题、推导、结果与假设；数值等式逐步计算残差。
- 力学：每个力保存方向、大小、作用点和证据；示例独立求和水平/垂直分量。
- 光学：保留物距、焦距、像距、放大率及构造光线；示例限定为薄透镜近轴模型。
- 化学方程式：反应物和生成物的元素清单必须逐元素守恒；示例不扩展到副反应或动力学。
- 实验室设备：设备、连接介质、方向和危险类别进入模型；真实使用需程序、仪表和属地安全复核。

## SysML v1 教学子集

- 需求图：覆盖 `«deriveReqt»`、`«satisfy»`、`«verify»`；每项需求至少被满足或验证。
- 块定义图：区分块、值类型、组合、泛化与类型关系。
- 内部块图：部件、端口和连接器分开；连接器两端的接口类型必须一致。
- 参数图：值属性经绑定进入约束块；计算残差不得超过输入容差。
- 这些示例依据 SysML 1.6 公开规范入口整理，只覆盖四种常用图的教学语义，不宣称完整工具兼容或 XMI 交换。

## 商务与信息设计

- 演示、愿景使命、年报、横幅、折页、封面、宣传单、杂志、新闻稿、海报、简报、名片、邀请卡与知识卡均声明纸张或像素尺寸。
- 每类要求专用内容角色：例如新闻稿包含标题、电头、导语、引语、事实和背景；邀请卡包含活动、主办、时间、地点和 RSVP。
- `reading_order` 必须与内容块顺序一致；每份模型还要声明受众与主行动。
- 演示类示例是一页一结论的结构骨架；不把静态页面误称为完成的演讲稿或品牌成品。

## 质量、云架构与分镜

- 品管七大手法：检查表、帕累托、因果、直方、控制、散点和分层必须齐全，并用同一数据集说明不同问题。
- 全面质量管理：顾客、领导、过程、人员、测量和改善形成治理—测量—改善—反馈闭环。
- 阿里云、腾讯云、华为云：至少两个可用区，显式身份控制与可观测节点；网络、计算、数据和流向均保留稳定 ID。
- 故事分镜：镜号连续，景别、动作、音频和时长必填；逐镜时长之和必须等于声明总时长。

## 重绘

```bash
python scripts/remaining_types.py assets/remaining-type-models/maintenance-storyboard.json --out ./out
```

编辑 JSON 后重新运行同一命令。不要直接修改 SVG 里的文字来伪造数据更新。

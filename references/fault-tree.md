# 静态故障树与最小割集

先定义顶事件、工况、系统边界和时间窗口，再从直接充分原因逐层分解。此后端支持静态相干AND/OR模型：AND要求所有输入发生，OR要求至少一个输入发生，不表示先后顺序。基本事件不再向下展开。相同故障在多个分支出现时保留同一ID；图中允许重复展示，但计算始终使用同一事件。

输入events中定义id、label、kind（basic/AND/OR）；门事件给inputs引用ID。top指定顶事件，scope明确工况，data_status标识真实/假设。拒绝环、未定义引用、未连接到顶事件的定义、同一门内重复输入和未知门。概率字段只有在下文明确的定量模式中接受，不能悄悄忽略数据。

最小割集通过集合并集/交叉乘积及吸收化简得到。割集内事件必须共同发生；不同割集为替代组合。重复ID不会生成两次独立失效，包含更小充分组合的超集被消去。“最小”指不能删除任何成员，不表示只保留成员数最少的一组。没有概率时不排序风险，不将割集个数解释为失效概率。

符号与版式：事件描述用矩形，基本事件接圆，AND门上圆下平，OR门尖顶且输入侧内凹；门旁标注AND/OR。连接不加流程箭头，父事件在上、输入原因在下。同一ID的多个视觉实例加重复标记；分析JSON保留唯一ID。SVG与draw.io使用原生向量和自定义门形状，输入修改应重绘。

```bash
python3 <skill-dir>/scripts/fault_tree.py <skill-dir>/assets/fault-tree-examples/shared-supply.json --out <output-dir>
```

专用提示词：明确顶事件与运行边界，核对每个门的充分条件，区分重复事件与不同组件的同类故障。保留事件ID，给出静态AND/OR模型、可编辑图和最小割集；检查所有布尔赋值的一致性，不擅自添加概率、独立性或动态时序假设。

实现容量：80个事件定义、每门2–10输入、100个视觉实例、8层深度、最长8000px；图上最多列30个割集。计算中间展开超过50000项或最小割集超过2000项会明确拒绝，应拆分或选用BDD工具，不截断后冒充完整结果。

来源：[NASA Fault Tree Handbook with Aerospace Applications](https://s3vi.ndc.nasa.gov/ssri-kb/static/resources/Fault%20Tree%20Handbook_NASA.pdf)，第4章符号、第5.6节重复事件命名、附录A布尔化简与最小割集。测试独立复算附录示例，期望割集为{C}和{A,B}。

待补：未展开/条件/转移事件，k-out-of-n、INHIBIT、非相干NOT/XOR、动态PAND/SPARE/FDEP，相关性/共因参数、概率不确定性、多页转移、BDD大规模求解。当前示例中的共同供电事件是一项明确建模的共享原因，不等于实现统计共因失效模型。不得据此宣称正式安全认证或全故障树能力完成。

## 独立基本事件定量模式

显式设置 `probability_model: "independent_bernoulli"`，提供 `probability_basis`（统一任务/时间窗口）和 `independence_justification`。每个basic事件必须有[0,1]内的有限概率与`probability_source`。门概率由逻辑计算，禁止输入覆盖。未声明独立性、混入未知概率或缺来源时拒绝计算；这只是输入契约检查，不能代替对独立性和数据口径的专业核实。

`fault_probability.py`对完整割集表达式做带缓存的Shannon分解，按变量为真/假拆成互斥情况，再计算加权概率；相同事件ID只是一项随机变量。没有稀有事件近似，没有将重叠割集概率直接求和。“完整”指给定布尔模型的概率计算，仍有浮点舍入误差和输入不确定性。分解超过100000状态会拒绝，不返回截断结果。它仍先生成割集，不是绕过割集容量限制的通用BDD后端。

示例`shared-supply-probability.json`采用教学概率A=0.1、B=0.2、C=0.3；顶事件C OR (A AND B)的概率为0.314，割集概率相加0.32包含交集而不等于顶事件概率。不得把这组假设数值当现场可靠性结论。分析JSON保留基本概率、来源、口径、独立性说明和每个割集的概率，图上展示顶事件结果及前提。

来源补充：NASA手册第6.2–6.3节对互斥分解与概率计算的说明、第7.1节对割集求和近似的限制。当前不支持相关事件联合分布、故障率向概率转换、维修模型、动态故障树或概率置信区间。

# 分享图册的六套新色

用于用户要求“更多配色、多元化，但克制、有质感”的场景。色板只改变视觉角色，不能改变数据、因果关系、刻度、正负符号和排序。保留原版，不覆盖用户之前选定的颜色。

定义位于 `assets/share-palettes.json`。原有暖纸墨线、蓝墨书页、石墨图谱保留；本轮新增：

| ID | 名称 | 主要用途 |
|---|---|---|
| cedar | 苔绿手稿 | 经营复盘、改善分析、科研分布 |
| plum | 梅紫书页 | 策略、销售、研究摘要 |
| midnight | 午夜靛蓝 | 软件架构、网络、技术汇报 |
| petrol | 深海矿青 | 系统架构、流程、模型连接 |
| ochre | 砂岩赭墨 | 管理汇报、计划、经营数据 |
| frost | 冷白钴墨 | 科研矩阵、三线表、结构说明 |

优先提供一浅一深的同内容对照：苔绿手稿 + 午夜靛蓝。用户未选定时，不把该推荐当作永久偏好。喜欢更独特的色相可比较梅紫书页或深海矿青。

## 视觉角色

- `bg` 是底色；`ink` 是正文及标题；`muted` 是辅助文字。注释应更轻，但仍然能读。
- `accent` 用于一组主要数据或核心路径，`cool` 用于第二组或另一种语义；两者不自动等价于正负、好坏或显著性。
- `tint` 用于局部填充；`line` 只承担弱网格、辅助参照。主要节点的边框使用独立的 `border`，避免随网格一起变淡。
- 不给每个节点涂一种颜色。不用彩色渐变替代可辨的数值编码。控制大面积色块，靠字体、留白和线条层级组织信息。
- 新增六套的四种文字颜色在 `bg` 和 `tint` 上分别计算对比度，最低 4.5:1；主要边框对底色最低 3:1。原三色原样保留，不把这些阈值反向声称为原版的验证结果。Token 对比度不能替代实际字号、线宽、抗锯齿和缩小成图检查。
- 相关性、正负贡献等仍保留数字、符号及文字；网络的非聚焦连接可弱化，聚焦关系必须清楚。

## 重绘已有图版

`scripts/recolor_plate.py` 只读取 `style_family.Plate` 的场景格式，不接受任意 SVG 或其他后端的场景。需要同前缀的 `.scene.json` 和 `.input.json`，有统计结果时也带 `.analysis.json`。

```bash
python3 <skill-dir>/scripts/recolor_plate.py <source-dir>/<stem> \
  --palette cedar --out <output-dir>
```

输出 PNG、SVG、PDF 与 QA JSON；`--vector-only` 只生成 SVG 与 QA。此工具保持源画布与几何尺寸，DPI 为 240；不是横竖自适应重排工具。换比例请先按 `canvas-sizing.md` 的后端规则重新布局。

脚本校验数据摘要、几何坐标、字号、线型、箭头和对象连接不变，仅替换页脚配色名称与已知的图例色名措辞（如将固定的“蓝墨、陶土”改为“两种墨色”）。新图应先完成语义模型及版式，再应用色板；不要拿这批示例的模拟数据替代真实输入。

## 验证范围

当前六套已在分享图册的十二种固定图版中生成：销售业绩、漏斗、瀑布、软件架构、数据架构、交付流程、鱼骨、甘特、小提琴、相关矩阵、消融表、MLP。每套 12 张，共 72 张 3840×2160 PNG，配有 SVG。

这不是全目录、全部比例或所有渲染器的适配证明。其他图型需映射对应的语义角色并检查成图。原图数值、数据与布局保持一致，便于公平比较色彩。

新增纯白版本另见 [纯白精研](white-precision.md)。它同时调整字体、线条和标记，使用独立渲染规则；不计入本页六套纯配色的 72 张，也不覆盖它们。

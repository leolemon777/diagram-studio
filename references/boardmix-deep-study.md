# 白板设计深入研究与 X 线索

日期：2026-09-20。目标是跨行业高频图示的构图与 UI/UX；不是模板全库复制，也不是完整产品评测。

## 覆盖与证据

前轮实际查看 4 种模板，本轮新增 8 种，累计 **12 种不同模板进入真实画布并看过截图**。下表是本轮新增；这不代表逐字阅读全部图元、测试所有交互或原生文件往返。新目录页出现登录窗口，但既有会员编辑会话中的模板中心可继续载入。本轮模板放在既有研究副本，并将其命名为“Diagram Studio · 模板研究副本 · 2026-09-20”；没有更改用户原有业务白板或对外分享。

| 模板 | 实际看到的结构 | 对本 Skill 的取舍 |
|---|---|---|
| 架构图 | 横向多层、层内嵌套分区、两侧贯穿能力、层间双向箭头，示例与空白板并列 | 区分包含关系与调用关系；横切能力可单列侧轨。模板中的箭头不能代替真实依赖，双向箭头需两向事实 |

| 服装设计企划 | 多种图片簇、色板、款式线稿、分类矩阵与文字资料共置；等待后图片完整加载 | 支持“参考—设计属性—候选方案”的资料板；不同材料有不同空间组织。只用合法素材，不复制模板中的图片或线稿 |
| 研究技术路线图 | 左侧阶段轨与右侧纵向多次分支/汇合逻辑，基本矩形与连接线 | 科研路线首先表达论证/方法关系，不是日历。阶段轨与方法节点要对应，不能只追求左右对称 |
| 事件风暴法 | 分步骤展示：事件序列、角色/动作补充、重新分组及边界视图 | 用多遍梳理保存原始事件到后续边界的映射；空间聚类不自动等于领域边界已得到验证 |
| 精益画布 | 大小不同的编号区域、部分上下拆区、底部横向区域、便签分类 | 保留各区的业务问题和阅读次序，按内容分配面积；不能把精益画布与商业模式画布合并成同一九宫格 |

以上为直接 UI 视觉观察，入口：[Boardmix](https://boardmix.cn/app/home)。商业模板资产和私有白板链接不打包进 Skill。

## 真实交互检查

- **模板上下文**：在编辑器内打开模板中心、查看详情、使用模板，载入研究副本；新增模板可同时存在于一张大画布。
- **对象上下文**：单击旅程便签出现浮动工具栏；双击进入文字编辑入口，显示字体与字号。后续 v43 在独立创建的研究便签中增加约三段长中文：100% 视图下宽度保持、卡片向下扩展，撤销后原内容和高度恢复。仅此模拟便签实测，不外推到容器或全部文本样式，也不等于导出重开通过。
- **阅读模式**：实际进入，编辑工具隐藏、保留图钉导航，并提示 Escape 退出；已退出回到编辑模式。阅读模式不意味着全画布字号自动可读。
- **导出对话框**：实际在独立创建的模拟白板中打开图片导出设置，选择 SVG、全区域、无水印并看到成功提示；PDF 选择 16:9、无边距、全区域并看到成功提示；Markdown 列出 3 张便签并成功导出。JSON 明确提示自由白板没有可导出的思维导图内容。浏览器自动化下载面没有把文件字节暴露到本机，因此这些是 UI 成功证据，不是字节级文件验收；记录见 [Boardmix 导出试验](../assets/boardmix-export-trial-evidence.json)。
- **分页风险**：加入新模板后，导出仍显示原有 2 个图钉页；因此不能认为“导出分页”自动覆盖全部新内容。交付前需核对源对象集合与导出范围。
- **文件命名**：研究副本改名成功。私有研究文件保留供用户回看；不从用户账户导出商业素材到公共仓库。

## X 公开作品本体补查（v43）

彭宏浩帖子中的公开 Boardmix 作品可只读打开。它是用户作品，不计入前述 12 种模板。实看整个长画布的分区组织、一处报错与解决方法局部，以及点击“整体的流程”图钉后的步骤区域。该区用文字步骤配截图，截图中有箭头与框选注释；侧栏有 7 个具名图钉，涵盖阅读前提、整体流程、环境、执行步骤、链接汇总和配置。此次未逐字审阅 7 区内容，也没有执行其中任何命令。

独立提炼：过程资料板应把步骤、证据截图和处理说明关联起来；具名导航要描述读者任务。这个观察支持来源追踪、清晰阅读与明确下载范围，不代表学到了作者的全部版式规则。X 附图本身仍未读取，作品本体的可访问性不等于 X 图片门槛已解除。

v43 已落地 [专用故事地图](story-map.md)：根据文字测量扩展卡片与行高、每个故事唯一归属、保留来源、中英完整内容切换，且明确全部下载范围。选图向导取消亲和图后端不支持的 draw.io 选项。

## 可以执行的改进顺序

以下是独立设计判断，不是声称新渲染器已经实现。

1. **先补语义差异**：服务蓝图必须有边界线和交接；旅程保留观察→机会→行动；静态架构与动态交互分开，稳定 ID 相互引用。
2. **完整路径故事板**：用于界面/服务流程审查，列出前置条件、步骤、可见状态、分支、下一步和异常；保持低保真，确认路径后再精修界面。没有真实路径时标为提案。
3. **上下文工具与阅读**：只在相关对象上显示相关操作；进入阅读时保留当前位置和具名导航，退出后恢复上下文。浮动工具不能遮住正在编辑的文字。
4. **导出是一个明确步骤**：先选图/分区、再选格式和背景、最后看预览。显示包含的分区名称与缺失对象，不凭分页数判断完整；待开发输出流程时验证，不宣称当前已具备全部交互。
5. **跨行业资料板**：允许图片簇、色板、线稿和关系图混排，但每类材料要回答一个问题；素材来源与事实状态可查。不要把研究、零售、创意都压成一套卡片。
